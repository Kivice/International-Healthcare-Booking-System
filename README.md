## 🏥 Overview

The **International Healthcare Booking System** is designed to reduce the friction of finding and scheduling appointments with registered medical practitioners across different cities. 

Built with semantic HTML5, modern CSS3 (Grid & Flexbox), and responsive UI patterns, the platform provides an accessible, clear experience for patients seeking urgent care, diagnostic services, or routine consultations.

---

## ✨ Key Pages & Features

* **Home (`index.html`):** Clinical care overview, core healthcare pillars, specialist highlights, and direct appointment inquiry forms.
* **Clinical Services (`services.html`):** Dedicated department breakdowns including:
  * 🚑 *Emergency Medical Care* — 24/7 triage guidance and trauma support.
  * 🔬 *Diagnostic Laboratory Services* — Pathology, blood chemistry, and imaging workflows.
  * 🦷 *Dental & Oral Surgery* — Preventive checkups, orthodontics, and restorative care.
  * 🩺 *General & Specialized Consultations* — Family medicine, cardiology, and pediatrics.
* **Medical Specialists (`meet.html`):** Verified healthcare practitioner directory featuring credentials, clinical specialties, and localized practice hours.
* **Patient Testimonials (`testimonials.html`):** Patient reviews, satisfaction metrics, and verified feedback.
* **Responsive Layout:** Optimized for desktop monitors, tablets, and everyday mobile smartphones with zero heavy framework overhead.

## 💻 Local Preview & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kivice/International-Healthcare-Booking-System.git
   cd International-Healthcare-Booking-System
   ```

2. **Open in browser:**
   Double-click `index.html` or run a local static server:
   ```bash
   # Python 3
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000` in your web browser.
