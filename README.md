## 🏥 Overview

The **ApexCare International Healthcare Booking System** eliminates the friction of searching for, verifying, and scheduling consultations with registered healthcare providers worldwide. Designed with medical-grade clarity, accessible typography, and intuitive multi-step flows, the application provides an empathetic, dependable digital gateway for patients seeking urgent triage, diagnostic laboratory appointments, specialist consultations, or telemedicine sessions.

**Live Deployment:** [https://kivice.github.io/International-Healthcare-Booking-System/](https://kivice.github.io/International-Healthcare-Booking-System/)

## ✨ Key Pages & Core Architecture

* **Home (`index.html`):**
  * Clinical header, 24/7 emergency dispatch strip, and key metrics (15,000+ consultations, 99.4% satisfaction).
  * Interactive Quick Booking widget for instant department and physician routing.
  * Core Healthcare Pillars (Verified Practitioners, Accredited Diagnostics, Transparent Care, Emergency Triage).
  * Featured clinical leadership and high-throughput department previews.
* **Interactive Appointment Scheduler (`appointment.html`):**
  * Multi-step scheduling engine with dynamic department-to-doctor data binding.
  * Interactive time slot selector (Morning, Afternoon, and Evening consultation slots).
  * Real-time voucher preview with dynamic status tracking and digital verification codes (e.g. `APX-2026-XXXXX`).
  * Instant printable booking slip and persistent local browser history.
* **Clinical Services Catalog (`services.html`):**
  * Interactive department categorization (Primary Care, Specialist & Surgery, Diagnostic Laboratories, Emergency Care).
  * Procedure outlines, diagnostic prep details, pricing transparency, and direct pre-fill routing to the scheduling engine.
* **Medical Specialists Directory (`meet.html`):**
  * Comprehensive profiles of clinical leadership (CMO Dr. John Doe, Trauma Surgeon Dr. Jane Smith, Pediatrician Dr. Emily Johnson, Cardiologist Dr. Michael Brown).
  * Board certifications, hospital affiliations, language fluencies, and 1-click consultation scheduling.
* **Patient Testimonials & Reviews (`testimonials.html`):**
  * Authenticated patient testimonials across South Africa, Kenya, China, and the United States.
  * Interactive client-side review submission engine storing validated ratings locally.
* **Emergency Triage & Contact (`contact.html`):**
  * 24/7 Acute triage assessment guide.
  * Direct WhatsApp triage connection (`+254 708 746 611`) and hospital dispatch coordination.

## 🛠️ Technology Stack

| Layer | Technology | Details |
|---|---|---|
| **Structure** | Semantic HTML5 | Accessible, WCAG-conscious document structure |

## 💻 Local Preview & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kivice/International-Healthcare-Booking-System.git
   cd International-Healthcare-Booking-System
   ```

2. **Run a local static server:**
   ```bash
   # Python 3
   python -m http.server 8000

   # Or Node.js npx
   npx serve .
   ```

3. Open `http://localhost:8000` in your web browser.
