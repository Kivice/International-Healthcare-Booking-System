## 🏥 Overview

The **ApexCare Healthcare Portal Template** is an engineered digital clinical interface designed for rapid commercial deployment by healthcare providers, private medical practices, and healthtech ventures. Built with zero-bloat web standards, modular CSS custom property theming, and an interactive state-driven booking engine, it enables prospective clients to preview and license a production-grade patient scheduling experience without heavy framework overhead.

**Live Client Preview:** [https://kivice.github.io/International-Healthcare-Booking-System/](https://kivice.github.io/International-Healthcare-Booking-System/)

## ✨ Client Demonstration Features

* **Multi-Theme Switcher:** Live colorway preview in 4 modern medical aesthetics:
  * 🌊 *Clinical Sky* (`#0284c7`) — Modern hospital & primary care standard.
  * 🌿 *Medical Emerald* (`#059669`) — Holistic wellness & preventative health.
  * ⚡ *Healthtech Indigo* (`#4f46e5`) — Telehealth & private clinic venture styling.
  * 🌹 *Care Crimson* (`#e11d48`) — Specialized surgery & acute care focus.
* **1-Click Demo Patient Auto-Fill:** Prospective clients reviewing the booking workflow can click `⚡ Auto-Fill Demo Patient` on [appointment.html](https://kivice.github.io/International-Healthcare-Booking-System/appointment.html) to instantly populate sample medical data, select real-time consultation slots, and generate digital appointment vouchers with verification codes (e.g. `APX-2026-XXXXX`).
* **Interactive Modular Catalog:** Services and medical staff directories feature transparent pricing scopes, diagnostic prep checklists, and 1-click booking pre-fills.
* **24/7 WhatsApp Triage Dispatch:** Direct integration hooks for patient WhatsApp messaging, emergency hotline triggers, and hospital routing.
* **Zero-Bloat Performance:** Sub-35 KB compressed payload with instantaneous first paint (< 30ms render latency) ensuring accessibility on any smartphone or metered cellular network.

## 🛠️ White-Label Architecture & Deployment Specs

| Module | Implementation | Client Customization Scope |
|---|---|---|
| **Branding & UI** | CSS3 Custom Properties (Design Tokens) | Logo, clinic palette, custom typography, favicon (< 48 hrs) |
| **Doctor & Schedule Engine** | Vanilla ES6+ State & Dynamic Slotted DOM | Connects to PostgreSQL, Supabase, Google Calendar, or FHIR APIs |
| **Digital Verification** | Client-side Voucher Engine & Slip Generator | Printable slips, barcode/QR integration, `.ics` calendar files |
| **Triage & Communications** | WhatsApp Webhooks & Twilio SMS Bridge | Automated SMS reminders, WhatsApp triage routing, email receipts |
| **Telemedicine Room** | WebRTC / Video Bridge Embeds | Plug-and-play compatibility with Daily.co, Twilio Video, or Jitsi |

## 💻 Local Preview & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kivice/International-Healthcare-Booking-System.git
   cd International-Healthcare-Booking-System
   ```

2. **Run a local static server:**
   ```bash
   # Python 3
   python -m http.server 8000

   # Or Node.js
   npx serve .
   ```

3. Open `http://localhost:8000` in your web browser.
